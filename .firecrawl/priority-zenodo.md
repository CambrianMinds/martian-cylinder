# Morphological and Photometric Analysis of an Unidentified Cylindrical Feature in Curiosity Sol 3556 Mastcam Imagery: Constraints on Aeolian, Diagenetic, and Artificial Provenance via Sub-Pixel Gradient Forensics

### Authors/Creators

- [Bogner, Justin1](https://zenodo.org/search?q=metadata.creators.person_or_org.name:%22Bogner,+Justin%22)

Show affiliations


- 1.



Cambrian Minds


## Description

Complete NASA Planetary Data System (PDS) raw telemetry, calibrated image products, LaTeX/Markdown manuscripts, interactive 3D central-perspective photogrammetry studio, and deterministic Python verification suite for the forensic investigation of the cylindrical anomaly imaged by the Mars Science Laboratory (Curiosity) Mastcam Right (100 mm) camera on Sol 3556 (August 7, 2022) at Paraitepuy Pass in Gale Crater (PDS Product ID: 3556MR1025170721700585C00). Technical Report CMR-2026-01.
